# Kisan Sahayak Release Artifacts

This folder contains the current Android debug APK and a mobile prototype screenshot.

## Android APK

Install `Kisan-Sahayak-debug.apk` on a connected Android device with:

```powershell
adb install Kisan-Sahayak-debug.apk
```

The APK was built from the current source with `assembleDebug` after a successful `npm run android:sync`.
